Firefox Form Filler

Review and fill job applications on websites you choose to trust. Your saved answers stay in Firefox local extension storage.

Install in Firefox

Checking for a Firefox release…

Download release XPI

After downloading a signed .xpi file, open Add-ons and themes in Firefox, choose the settings gear, then Install Add-on From File. Select the downloaded file and approve Firefox’s prompt.

Source code and release history: firefox-form-filler on GitHub.

Developer Edition test build

This is the unsigned v1.8.2 development XPI. It is for Firefox Developer Edition, not standard Firefox. When installed from this web link, Firefox can use the extension's HTTPS update manifest for later higher-version builds.

Install unsigned development XPI

Before installing, export a private profile backup from the extension options. Firefox Developer Edition must have xpinstall.signatures.required set to false; this disables add-on signature enforcement in that browser profile. Install from the button above rather than as a temporary add-on or through Install Add-on From File. Later, use Add-ons and themes → gear menu → Check for Updates.
